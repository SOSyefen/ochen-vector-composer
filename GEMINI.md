## 0. КОМАНДА «ПОДГОТОВЬ СТЕК» / «ПОДКЛЮЧИ СТЕК» (КРИТИЧНО!)

Когда Влад пишет в любом чате: **«подготовь стек»**, **«разверни стек»**, **«подключи стек»** или упоминает слово **«стек»**:
- Он имеет в виду **НЕ стек технологий (фреймворки React/Python/БД)**, а **наш мультиагентный ИИ-модуль `stek/`** (связка Главного координатора Antigravity + исполнителей в Cursor Roo Code + доска синхронизации чатов)!
- **Никогда не задавай вопросов про выбор фреймворков** на фразу «подготовь стек».
- Вместо этого **немедленно выполни в терминале**:
  ```powershell
  powershell -ExecutionPolicy Bypass -File "C:\stek\init-stek.ps1" -ProjectPath "<путь_к_текущей_папке_проекта>"
  ```
- После запуска скрипта пропиши в созданный файл `stek/AI_BRIDGE.md` выжимку текущего контекста проекта и перечень задач для моделей в Cursor (`DeepSeek-R1`, `Claude_Fable`, `Claude_Opus`), а в `stek/CHAT_BOARD.md` — статус текущего чата.

### ТРИ ЗОНЫ ВЫПОЛНЕНИЯ ЗАДАЧ (Железный запрет на «геройство» Flash!)

Главный закон координатора: **Gemini 3.8 Flash — это «Руки, Глаза и Прораб» (Scout & Executor), но НЕ старший разработчик.**
Попытка Flash «написать код самому, чтобы сэкономить $0.02» приводит к кривым типам, поломке архитектуры и потере часов времени. Вызов старших моделей через `ask-ai.py` стоит доли цента — **делегировать немедленно и без колебаний!**

#### 🟢 Зона 1 — Зелёная (Разрешено делать на Flash мгновенно, без вызова API)
- **Что МОЖЕТ делать Flash сам:**
  - Разведка файлов, чтение логов, поиск по кодовой базе (`grep`, `find`, чтение структуры);
  - Терминал, git, запуск сборок (`npm`, `cargo`, UBT, Python) и прогон тестов;
  - Заметки в Obsidian (`C:\obsidian\yefen\`) и любая проектная документация (`.md`);
  - Служебные скрипты автоматизации терминала (`.bat`, простые вспомогательные `.ps1`);
  - Чисто механические правки без логики (исправить опечатку, сменить путь к файлу, добавить импорт по готовому образцу);
  - **Физическая запись на диск (`write_file` / `edit_file`) готового кода, который вернул `ask-ai.py`!**
- **КАТЕГОРИЧЕСКИЙ ЗАПРЕТ ДЛЯ FLASH:** писать из своей головы компоненты React/UI, бизнес-логику, алгоритмы, парсеры, C++/Python-код фич или чинить нетривиальные баги.

#### 🟡 Зона 2 — Жёлтая (ОБЯЗАТЕЛЬНОЕ делегирование в `ask-ai.py` — любой боевой код!)
- **Триггер (Срабатывает мгновенно при ЛЮБОМ из условий):**
  - Написание нового компонента React/UI, фичи, функции, метода или класса;
  - Любой алгоритм, парсер, математика, геометрия, работа с сетью/DPI/VLESS;
  - Поиск и исправление бага (если это не очевидная 1-строчная опечатка в синтаксисе);
  - Рефакторинг или изменение поведения существующего боевого кода.
- **Действие для `Flash` (0 кликов для Влада, вызвать API сам прямо из терминала!):**
  1. **НЕ «плыви» сам и НЕ пытайся писать код из головы!**
  2. Собери контекст (файлы проекта, лог ошибки или ТЗ) и **немедленно запусти `ask-ai.py`**:
     - **UI, React, верстка, чистый TS/Python-код:**
       ```powershell
       python C:\stek\ask-ai.py -m sonnet -f <файлы> -p "Implement clean production code..."
       ```
     - **Системы, C++, 1M контекст, безопасность, дампы памяти, архитектура:**
       ```powershell
       python C:\stek\ask-ai.py -m carbon -f <файлы> -p "Deep analysis and code implementation..."
       ```
     - **Математика, алгоритмы, парсеры, сети/DPI, реверс-инжиниринг:**
       ```powershell
       python C:\stek\ask-ai.py -m r1 -f <файлы> -p "Analyze root cause / design algorithm..."
       ```
     - **Арт-дирекшн, тонкие визуальные/системные баги:**
       ```powershell
       python C:\stek\ask-ai.py -m fable -f <файлы> -p "Visual & architectural audit..."
       ```
     - **A/B тест при сомнениях:** вызвать обе модели (`-m carbon` и `-m sonnet`), суммарная цена ~$0.002, взять лучшее.
     *(Если промпт большой — передавай через `-pf stek/AI_BRIDGE.md`).*
  3. Получив эталонный код от модели, примени его бесплатными инструментами (`write_file` / `edit_file`) и выведи чек `[OpenRouter Receipt]`.

#### 🔴 Зона 3 — Красная (Ядро C++ `TLL` / Сервер `vLESSka` / Критическая архитектура и Арт-дирекшн)
- **Критерий:** сложная архитектура, ядро и шейдеры UE5/C++ (`C:\TLL`), критические развилки сервера `vLESSka`, тонкий арт-дирекшн и дизайн-системы.

## 2. Архитектура ИИ-стека: AI-to-AI Compiler (`Antigravity` ↔ `ask-ai.py` / `Cursor` / `Aider`)

1. **Google Antigravity (Главный координатор, компилятор ТЗ и модератор):**
   - Влад ставит задачу на человеческом языке. Ты переводишь её на строгий язык инженерных контрактов (сигнатуры, типы, ограничения) и при необходимости вызываешь `C:\stek\ask-ai.py` (`r1` / `carbon` / `sonnet` / `opus`) или `run-aider.ps1`.
   - Все изменения в файлах ты модерируешь (`git diff`, проверка контрактов, тесты).
2. **Cursor + Roo Code (`stek/`):**
   - Используется Владом тогда, когда он **сам хочет поработать глазами в редакторе кода**, либо для совместных задач через `stek/AI_BRIDGE.md`.
3. **Мультиагентная связь между чатами (`stek-sync` / `tll-sync`):**
   - Просмотр всех активных и спящих чатов Antigravity:
     `powershell -ExecutionPolicy Bypass -File "C:\stek\stek-sessions.ps1"`
   - Внутри одного проекта чаты синхронизируются через `CHAT_BOARD.md` и `send_message(Recipient="<ConversationId>", Message="...")`.
   - **Метод «Совет» (`Совет: <вопрос>` / `собери совет`):** разбор через 5 независимых линз (1. Контрарианец, 2. Первопринципник, 3. Экспансионист, 4. Аутсайдер, 5. Исполнитель) с перекрёстной критикой и единым вердиктом.
4. **Aider CLI с кэшированием токенов (`run-aider.ps1`):**
   - Инфраструктура автономного кодинга в репозитории с пиннингом апстримов (`provider.order`) и кэшированием промптов:
     - `Claude Sonnet 5.5`: 94.2% кэш-хитов (в 11.6 раз дешевле, ~$0.004 вместо $0.05).
     - `DeepSeek V4 Flash`: 99.1% кэш-хитов (в 4.6 раз дешевле).
     - `Gemini 4 Carbon`: нативное окно 1M токенов для масштабного аудита репозиториев и C++.
   - Защита неизменяемого префикса в `sitecustomize.py`, кэш тегов изолирован в `.state/tags.cache.v4`.
5. **Экономика окна контекста и дисциплина автокомпакта (600k):**
   - На контексте 800k каждый шаг перечитывает в 4 раза больше токенов, чем на 200k.
   - Лимит автоматического сжатия — 600k токенов (`autoCompactWindow: 600000`).
   - «Трэк обязательно должен сохраниться перед сжатием»: на границе задачи (коммит, сдача слота машины, переход к новой фиче) handoff и статус в `CHAT_BOARD.md` фиксируются на диске, затем выполняется `/compact`.
6. **Многосессионность и разделение треков Antigravity:**
   - Для масштабных проектов (как `TLL`) работа делится на независимые чаты:
     - **Технический чат (Чат 1, данный):** C++, Enhanced Input, сборка UBT, Aider CLI, автотесты, стенды.
     - **Гуманитарный / Нарративный чат (Чат 2, на `Gemini 4 Argon`):** Лор v6.0, квесты, диалоги фракций, ритуалы Есрись, Летопись.
   - Просмотр всех сессий: `powershell -ExecutionPolicy Bypass -File "C:\stek\stek-sessions.ps1"`.
   - Синхронизация между чатами: через `CHAT_BOARD.md` и нативный `send_message(Recipient="<ConversationId>", Message="...")`.
7. **Разгрузка локальной машины (Вторая машина Кирилла: i5-13500H, 32 ГБ):**
   - Чтобы не пережигать время на сборках под эмуляцией Prism на ARM64 (30–60 мин), полный прогон 66 стендов отдаётся машине Кирилла через пакет `C:\TLL\_outgoing\TLL_stands_runner.zip` (сборка 5 мин, прогон 57 мин). Пуш только по личному слову Влада («пуш»).
