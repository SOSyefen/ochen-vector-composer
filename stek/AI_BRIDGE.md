> - **Antigravity (Главный координатор и модератор, БЕСПЛАТНО):** держит всю память, ставит задачи агентам в Cursor, проверяет и модерирует их ответы перед внедрением на диск.

>   - **`Claude_Opus`** (`claude-opus-5.5`) — главная архитектура и сквозные контракты.

## 2. Текущий перечень задач для Cursor (Roo Code)
- **Кому назначено:** **`DeepSeek-R1`** (для алгоритма сборки) / **`Claude_Fable`** (для эталонных композиций)
- **Задача:**
  1. Реализовать **Сценарий 1** (по метафоре или заголовку) и **Сценарий 2** (по списку компонентов, например: «кошелек, наушники, ваза, ручка» или «книга, телефон, ручка»).
  2. Внедрить 3 схемы арт-директора из Figma («Примеры композиций»):
     - **Схема «Собранно» (Centered Island / Surface Stack):**
       - Точное воспроизведение референса арт-директора:
         - `notebook` (кошелек, Bg): база-подложка слева (`dx: -100, dy: -20, scale: 0.42`, tier: 0)
         - `vase` (букет цветов, Bg): глубокий фон за наушниками (`dx: 120, dy: -110, scale: 0.30`, tier: 0)
         - `headphones` (наушники, Main): опираются на кошелек (`dx: 20, dy: 30, scale: 0.42`, tier: 1)
         - `pen` (ручка, Main): акцент перед правым наушником (`dx: 110, dy: 75, scale: 0.38`, tier: 2)
       - Другие варианты подложек: `book` (Main/Bg) как база + `headphones`/`phone` сверху; `folder` (Bg) как база + `phone`/`puzzle`.
     - **Схема «Со смещением» (Asymmetric Offset):**
       - Лампа (`lamp`, Bg) на заднем плане слева (`dx: -190, dy: -120, scale: 0.32`)
       - Книга (`book`, Main) или смартфон по центру-справа
       - Монета (`coin`, Main) или ручка впереди справа (`dx: 170, dy: 80`).
     - **Схема «Под заголовок» (Under Headline):**
       - Вся диорама смещена вправо (`X ∈ [550..850]` в пространстве 1000px, то есть `dx ∈ [+150..+240]`), оставляя левую половину (`X < 500`) свободной для крупной типографики/заголовка.
  3. **Сценарий 2 — динамический резолвер:**
     - Функция `composeByComponentList(components: IllustrationId[], formatId: CanvasFormatId, layoutStyle?: LayoutStyle)`:
       - Интеллектуально распределяет переданные компоненты по ролям:
         - Базы (`book`, `folder`, `notebook`) -> tier 0
         - Высокий фон (`lamp`, `vase`) -> tier 0
         - Главные герои (`headphones`, `phone`, `puzzle`) -> tier 1
         - Акценты (`pen`, `coin`) -> tier 2
       - Назначает цвета/варианты (`Main` для героев и акцентов, `Bg` для баз и высокого фона).
     - Функция `extractComponentsFromText(text: string): IllustrationId[]`:
       - Парсит названия компонентов по-русски и по-английски (книга, смартфон, телефон, пазл, монета, монетка, наушники, лампа, букет, цветы, ваза, кошелек, блокнот, папка, ручка).
     - При вводе в Сценарии 1 списка предметов (например, «кошелек, наушники, ваза, ручка») — автоматический переход на сборку Сценария 2.
  4. Обновить `AiModal.tsx` с двумя вкладками:
     - Вкладка 1: «Сценарий 1: По метафоре / смыслу» (поле ввода + чипсы пресетов).
     - Вкладка 2: «Сценарий 2: По списку компонентов» (выбор чипсами из 10 предметов + поле ввода + пресеты, включая эталон арт-директора).
