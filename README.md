> **Тестовое задание на позицию Junior AI Developer**  
> Интерактивный веб-сервис для автоматизированной и ручной сборки изометрических иллюстраций из векторной библиотеки компонентов без растеризации.

## ✨ Реализованный функционал по чек-листу ТЗ

### 1. Библиотека компонентов и работа с SVG (10 канонических предметов)
- **10 канонических объектов** в двух размерах детализации (**Размер L** — высокая детализация, **Размер S** — лаконичная графика):
  1. `book` (**Книга**) — раскрытый фолиант;
  2. `phone` (**Смартфон**) — современный телефон с лавандовым стеклом;
  3. `puzzle` (**Пазл**) — две соединяющиеся детали (желтая и розовая);
  4. `coin` (**Монета**) — золотой жетон с замком;
  5. `headphones` (**Наушники**) — накладные наушники с белым ободом, лавандовой подушечкой и желтым диском;
  6. `lamp` (**Лампа**) — высокая настольная лампа;
  7. `vase` (**Букет цветов**) — белая ваза с тюльпанами;
  8. `notebook` / `wallet` (**Кошелек**) — сиреневое портмоне с кнопкой;
  9. `folder` (**Папка**) — папка для документов;
  10. `pen` (**Ручка**) — авторучка с золотым клипом.
- **2 состояния каждого объекта**:
  - `Главный (Main)` — полноцветный акцентный вектор;
  - `Фоновый (Bg)` — монохромный лавандовый контур/тень.
- Итого **40 чистых векторных SVG-ассетов** (без артефактов и обрезки), извлеченных напрямую из мастер-слоев Figma.

### 2. Сценарий 1: Сборка по метафоре или заголовку
- Пользователь вводит заголовок статьи или метафору (например: *«Финтех и аналитика»*, *«Глубокий фокус в дедлайн»*, *«Командный брейншторм»*, *«Сцена под заголовок»*).
- Семантический классификатор определяет смысл, подбирает релевантную группу предметов, рассчитывает роли и собирает сбалансированную композицию.

### 3. Сценарий 2: Сборка по списку компонентов
- Пользователь выбирает нужные компоненты интерактивными чипсами или вбивает названия текстом (например: *«кошелек, наушники, букет цветов, ручка»*).
- Алгоритмический резолвер распределяет предметы по физическим изометрическим слоям:
  - **База-подложка** (`folder`, `book`, `notebook`/кошелек) -> `layerTier: 0`
  - **Высокий фон** (`lamp`, `vase`) -> `layerTier: 0`
  - **Главный герой** (`headphones`, `phone`, `puzzle`) -> `layerTier: 1`
  - **Акцент** (`pen`, `coin`) -> `layerTier: 2`
- Присутствует кнопка быстрого применения **«⭐ Эталон арт-директора»** в один клик.

### 4. Три канонические схемы расположения (Art Director Presets)
1. **«Собранно (Островок)»** — точное воспроизведение референса арт-директора:
   - Кошелек (`wallet`, Bg) как база слева (`dx: -100, dy: -20`);
   - Букет цветов (`vase`, Bg) в глубине (`dx: 120, dy: -110`);
   - Наушники (`headphones`, Main) чашей опираются на кошелек (`dx: 20, dy: 30`);
   - Ручка (`pen`, Main) лежит перед правым наушником (`dx: 110, dy: 75`).
2. **«Со смещением»** — асимметричный диагональный баланс: высокая лампа слева сзади, книга/смартфон по центру, монета/ручка справа впереди.
3. **«Под заголовок»** — смещение всей диорамы в правую часть полотна (`dx: +160..+240`), освобождающее левую треть под крупный заголовок и типографику.

### 5. Строгое соблюдение пропорций (Закон «НЕЛЬЗЯ»)
- Относительные пропорции предметов в Figma зафиксированы и не искажаются:
  - Базы: `book` (1447px, scale 0.38), `folder` (1243px, scale 0.42);
  - Высокий фон: `lamp` (1131px, scale 0.32), `vase` (748px, scale 0.30);
  - Герои: `headphones` (883px, scale 0.42), `phone` (802px, scale 0.38), `notebook` (640px, scale 0.42);
  - Акценты: `pen` (517px, scale 0.38), `coin` (335px, scale 0.40).
- При переключении форматов (1:1, 16:9, 9:16) масштаб элементов согласуется автоматически.

### 6. Работа с цветовой палитрой и кастомный импорт
- 3 встроенные палитры:
  - **Lavender** (`#D7CDF5`);
  - **Sand & Peach** (`#FDD7B9`);
  - **Mint & Teal** (`#BEEBEB`).
- **Загрузка кастомной палитры**: в боковой панели доступен импорт JSON-палитры с автоматической перекраской сцены в реальном времени.
- **Соблюдение правила дизайн-системы**:
  > *«Цвета фонов могут использоваться в объектах. Цвета для объектов не могут использоваться в фонах».*
  Валидатор автоматически блокирует попытки сделать фон холста цветом из палитры объектов.

### 7. Экспорт чистого векторного SVG
- Скачивание автономного SVG без растра в 1 клик (`Скачать SVG`).
- Все слои, группировка, трансформации и векторные пути сохраняются для дальнейшего редактирования в Figma/Illustrator.

## 🏛️ Архитектура: хранение, извлечение и переиспользование SVG

```
src/
├── assets/
│   └── illustrations/       # 40 нормализованных векторных SVG-файлов (L и S)
│       ├── L_Main_*.svg     # Размер L, Главный (цвет)
│       ├── L_Bg_*.svg       # Размер L, Фоновый (монохром)
│       ├── S_Main_*.svg     # Размер S, Главный
│       └── S_Bg_*.svg       # Размер S, Фоновый
├── types/
│   └── index.ts             # Типы CanvasObject, Palette, CatalogItem, CanvasFormat
├── utils/
│   ├── svgRegistry.ts       # Реестр ассетов и метрик (Vite import.meta.glob)
│   ├── recolorEngine.ts     # Токенизация цветов, скоупинг и валидатор правил палитры
│   ├── aiComposer.ts        # Реализация Сценария 1 и Сценария 2 + 3 схемы арт-директора
│   └── svgExporter.ts       # Генератор автономного векторного SVG
└── components/
    ├── Canvas.tsx           # Интерактивный артборд (drag, rotate, scale, zIndex)
    ├── Toolbar.tsx          # Верхняя панель (размер L/S, форматы 1:1 / 16:9 / 9:16, экспорт)
    ├── Sidebar.tsx          # Каталог, слои, управление фоном и импорт JSON-палитры
    └── AiModal.tsx          # Модальное окно (Сценарий 1 и Сценарий 2 с выбором схем)
```

1. **Хранение (Storage):**  
   SVG-файлы хранятся в виде чистых векторных путей. Vite компилирует их в единый бандл через `import.meta.glob(..., { query: '?raw', eager: true })`, исключая задержки сети и лишние сетевые запросы.
2. **Извлечение (Retrieval):**  
   Функция `getRawSvg(id, size, variant)` мгновенно возвращает исходный вектор нужного размера и состояния.
3. **Перекраска (Recolor):**  
   Движок `recolorSvg()` сопоставляет заливки (`fill`) и обводки (`stroke`) с семантическими ролями палитры, производя замену без деформации геометрии.
4. **Сборка (Assembly):**  
   `assembleFullSvg()` генерирует чистый XML SVG-документ с правильным порядком слоев по алгоритму художника (`zIndex`).

## 🤖 Использованные AI-инструменты

В разработке использовался мультиагентный стек моделей:
1. **Google Antigravity (Gemini 3.8 Flash)** — координация проекта, глубокая разведка кодовой базы, автоматизация парсинга и сборки, live-тестирование через собственный Browser Bridge.
2. **DeepSeek-R1** (через консольный мост `ask-ai.py` OpenRouter) — строгий расчет алгоритмов изометрической компоновки, физического порядка слоев, парсера естественного языка для Сценария 2.
3. **Claude 3.5 Sonnet / Claude Fable 5.2** — арт-дирекшн аудит пропорций элементов, выверка канонических схем из Figma и дизайн-системы.
4. **Google Gemini 4 Carbon** — архитектурный аудит векторных дампов и кластеризация координат.
